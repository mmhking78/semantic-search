# AI LLM Class 11 - Mini Semantic Search

## Project Description

This project builds a Mini Semantic Search Engine
using Sentence Transformers and NumPy.

It converts text into embeddings and retrieves
the most relevant results for a search query.

## Model

all-MiniLM-L6-v2

Embedding Dimension: 384

## Features

- Text Embedding Generation
- Normalized Embeddings
- Embedding Cache using emb.npy
- Cosine Similarity
- Semantic Search
- Top-K Ranked Results
- KMeans Clustering
- PCA 2D Visualization
- English and Bangla Query Comparison
